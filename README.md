💻 Guía de Instalación del Himnario en ProPresenter (Windows)
Sigue estos pasos para añadir la biblioteca de himnos a ProPresenter:

I. Preparación de los Archivos
  Descomprimir: Localiza el archivo ZIP o RAR y descomprime la carpeta HIMNARIO_NUEVO en tu escritorio o en una ubicación temporal de fácil acceso.

II. Ubicación de la Biblioteca
  Crear Carpeta: Abre el explorador de archivos y dirígete a la ruta de las bibliotecas de ProPresenter:

  C:\Users\tu_nombre_de_usuario\Documents\ProPresenter\Libraries

  Nueva Biblioteca: Dentro de la carpeta Libraries, crea una nueva carpeta y nómbrala como desees, por ejemplo, HIMNARIO o Himnos.

    Alternativamente, puedes crear la nueva biblioteca directamente desde la interfaz de ProPresenter, lo que generará automáticamente la carpeta en esta ubicación.

III. Copia de Archivos
  Transferir Contenido:

  Entra en la carpeta HIMNARIO_NUEVO que descomprimiste en el Paso 1.

  Copia todos los archivos y carpetas que se encuentran dentro.

  Pega el contenido copiado dentro de la carpeta HIMNARIO (o la que hayas creado) en la ruta de ProPresenter (Paso 3).

IV. Finalización
  Reiniciar ProPresenter: Para que el programa detecte la nueva biblioteca, cierra completamente ProPresenter y vuelve a abrirlo.

Al reiniciar, el nuevo himnario aparecerá como una opción de biblioteca lista para usar.
